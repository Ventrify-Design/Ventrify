Common questions

What exactly do I get when I purchase?
You get the complete Ventrify Workflow file (4,242 lines), a demo video showing the workflow running on a real client engagement, and a step-by-step setup guide. One purchase, everything included.
Do I need to know how to code?
You need basic terminal comfort — navigating directories, running npm scripts, using Git. You do not need deep programming skills. The system handles the complexity; you handle the decisions. If you can open a terminal and follow instructions, you can run Ventrify OS.
What tools do I need?
VS Code (free), Claude Code (included with Claude subscription), Node.js 18+ (free), Git (free), and Figma Desktop (free tier). Everything you need is either free or included with tools you likely already have.
Can I use this for multiple clients?
Yes, unlimited. One purchase, unlimited engagements. You create a new project folder for each client, copy in the CLAUDE.md, and run the system again. There are no per-client fees or usage limits.
Is this a subscription?
No. £500 one-time payment. You pay once, you own the workflow. No recurring charges.
What if I get stuck?
The demo video walks through a complete real engagement from start to finish, and the setup guide covers every step. The workflow itself is heavily documented — 4,242 lines of structured instruction with comments throughout.
How is this different from a prompt template?
It’s 4,242 lines with gate reviews, payment enforcement, parallel workstreams, and 15+ automated tools. Not a prompt. A prompt template gives you a starting point. Ventrify OS gives you an entire operating system — with enforced phases, automated deliverable generation, quality gates, and integrated tooling that runs a full engagement from brief to launch.
