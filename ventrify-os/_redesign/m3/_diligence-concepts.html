Replacing the clearance chart

Today's Diligence hero is progressLockup in its native home: a big 0, a Do not wire chip, nine 7px pips and a caption. It is the most honest of the four heroes and still has two problems — it says 0 of 9 cleared three times over, and it implies all nine must clear before money moves, which the code itself does not believe.

Read the data line under each concept first. The runner emits each check as one free-text item plus a free-text priority; the adapter splits the item into a title and a note and maps the priority onto three severities. Counts are never 3/3/3 by rule — a clean assessment can be 0/2/4.

⚠ The one thing worth deciding before the chart. done is hardcoded false in the adapter, the checkboxes in the list below the hero are bare <div>s with no handler, and nothing anywhere in the OS ever writes a cleared state for an assessment check. So “0 of 9 cleared” reads zero on every assessment, forever — today's chart is a progress bar that cannot progress. Each concept below is therefore drawn twice: as it looks today (nothing cleared, the only state that ships) and as it would look if clearing were wired up. Concepts 01, 02 and 06 stay useful in both; 03, 04 and 05 are mostly waiting for a feature that does not exist yet.
