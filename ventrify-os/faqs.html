Pricing
How much does the workflow cost? +

£500. One-time payment. No subscription, no recurring fees.

Is the price in different currencies? +

Yes — the site auto-detects your location and shows the price in your local currency (GBP, USD, AED, CAD, or SGD). The actual transaction will be in GBP via Stripe, with your card’s normal currency conversion.

Are there discounts for multiple seats? +

The workflow is licensed per operator. Contact us for team licensing if you need multiple seats.

Do I get future updates? +

Yes. All workflow updates are free for life. When new features, agents, or tools are added to the system, you get them at no extra cost.

What’s your refund policy? +

If the workflow doesn’t run on your machine after following the setup guide, we’ll refund you in full within 14 days of purchase.

Setup
What do I need to install before I can use this? +

VS Code (free), Claude Code extension (requires a Claude subscription), Node.js 18+, and Git. The setup guide walks you through installing each one.

How long does setup take? +

Around 30 minutes if you’re starting from scratch. Faster if you already have VS Code and Node installed.

Do I need a Claude API key or subscription? +

Yes. You need an active Claude subscription to use Claude Code. The workflow runs entirely through Claude Code — we don’t access any APIs separately.

Can I run this on Windows? Mac? Linux? +

All three. The workflow uses cross-platform tools (Node, Git, VS Code). Some optional tools like FFmpeg need separate installation per OS — covered in the setup guide.

What if I get stuck during setup? +

The setup guide covers common issues. If you hit something the guide doesn’t cover, email hello@ventrify.io and we’ll help.

Technical
Do I need to be a developer? +

No. Basic comfort with VS Code and a terminal is enough. If you can run npm install, you can run this workflow.

What programming languages does this use? +

The workflow uses Node.js (JavaScript) for tools and PDF generators. The MVP app is built with React Native (JavaScript/TypeScript). The marketing site is Next.js. You don’t need to write any of this — Claude does.

Does this require a database or backend server? +

No. The workflow itself runs entirely in your code editor. The deliverables it produces (apps, websites) may use external services like Firebase, but the workflow doesn’t require its own backend.

What if Claude makes a mistake? +

The workflow includes 3 QA validators that catch errors before deliverables ship. The persistent memory system also learns from past sessions. You always review and approve outputs at each gate review.

Can I customise the workflow? +

Yes. The CLAUDE.md file is yours to edit. You can adjust phase orders, add your own deliverables, customise the brand kit defaults — anything. The workflow is a starting point, not a cage.

Deliverables
What does the workflow actually produce? +

70+ deliverables across 7 categories: research (7 docs), definition (7 docs), 4 PDF presentation decks, MVP app (iOS + Android), marketing website, design system + 3 Figma plugins, social content, video, and operations files (SOW, invoices, portal). See the showcase page for examples.

Are the deliverables fully branded for each client? +

Yes. The brand kit step in Phase 0 captures the client’s colours, fonts, logo, and tone. Every deliverable uses these — including 37 auto-sourced brand photos that match the client’s industry and style.

Can I sell the deliverables to my client? +

Yes. Anything the workflow produces is yours to deliver to your client. They become the IP owner once you hand off.

How long does a typical engagement take? +

6–8 weeks from brief to launched product. Some phases run in parallel, which is what makes the speed possible.

What if the client wants something the workflow doesn’t include? +

The workflow handles 70+ standard deliverables. For anything custom, you can extend the workflow yourself or invoice the client separately.

Ownership
Who owns the deliverables I produce? +

You do. Once you hand off to your client, they own the IP. You own the workflow you used to produce it.

Can I share the workflow with team members? +

The workflow is licensed per operator. If multiple people in your team will be running the workflow, you need multiple licenses.

Can I resell the workflow itself? +

No. The workflow is licensed for your use to deliver client engagements. You cannot redistribute, resell, or rebrand the workflow itself.

What happens if Ventrify shuts down? +

The workflow you’ve purchased is yours forever. It runs entirely on your machine through Claude Code — there’s no Ventrify server it depends on. Even if we vanished, your workflow would keep working.
