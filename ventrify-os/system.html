The Agents

47 specialist AI agents.
7 domains. 3 substrate keystones.

Each agent is anchored to a specific failure mode it prevents. Three of them are load-bearing for the entire fleet — if you took just one away, the cracks would compound across every other agent’s work.

Substrate · The 3 Keystones
founder-lexicon-keeper
Fires at · Phase 0 + post-hook every writer

Canonical vocabulary & voice principle enforcer. Every writing agent (copywriter, social, blog, email, pitch script) reads its output before opening their mouth. Without it, the content fleet ships voice-adjacent output with drift.

workflow-orchestrator
Fires at · Session start + daily cron

The routing layer. Reads state, produces a daily briefing, surfaces what fires next for the program manager. The fleet’s air-traffic control.

agent-output-validator
Fires at · Mandatory post-hook on every agent run

Catches silent failures within 30 seconds. Outputs present, non-empty, quality-checked. The fleet’s immune system.

Build-First 8 · Compounding agents

Layer 2 · Quality-substrate tools (14)

Deterministic Node scripts that run before, during, and after every agent. They’re what stop the platform behaving like an LLM — ground truth lives in code, not in a model’s memory.

brand-token-validator

Diffs tokens.json against every consumer. Blocks ship if app, marketing site or video colour grade drift.

financial-cross-ref

Cross-references cap table, financial model and deck numbers. Mismatches surface as red blocks.

lexicon-diff

Checks every writer output against the canonical lexicon. Banned words, drift terms, persona-name leaks — all caught.

citation-verifier

HTTP-checks every URL in research. Flags hallucinated sources before they reach the Research Hub.

visual-diff

Pixel-diffs Figma artboards against shipped components at every gate.

a11y-audit

WCAG AA contrast + nav structure + alt-text checks. Phase 4 cannot close without a pass.

deliverable-manifest-check

Verifies every tier-required deliverable exists, is non-empty, and lives at the expected path.

screenshot-orchestrator

Headless capture run with deterministic naming. Single capture dir feeds marketing, deck, App Store, video.

pdf-quality-gate

Renders every PDF deliverable to pixels and runs structural + visual gates before release.

repo-state-snapshot

Daily state capture — feeds workflow-orchestrator with deterministic ground truth.

gate-precheck

Runs the gate criteria as code. Founder is only invited to sign once the precheck returns green.

scope-diff

Compares SOW vs delivered. Flags scope creep and silent under-delivery before invoicing.

handoff-bundle

Compiles the Phase 5 handoff: brand kit, code, deck, financials, portal credentials. One signed bundle.

investability-scorer

TDK 7×5 Investability rubric, scored deterministically off the data room. Surfaces in the founder portal.

Substrate tools run on a cron, on file-save hooks, and as mandatory post-checks after every agent. The fleet only ships work the substrate has signed off.
