The Agents

10 specialist AI agents.
One orchestra.

Each agent has a specific phase, a specific input, and a specific output. The platform runs them in sequence so a single program manager can ship what used to take 10 people.

research-curator
Phases 1, 2, 2.5

Reads each L3 research document and drafts 5–7 Provocation Cards per hub. The card layer of the data room.

source-verifier
End of Phase 1

Fact-checks every source in the Research Hub. Flags hallucinated citations and impossible numbers before the gate.

information-architect
Phase 2

Maps every feature to a screen. Produces the full IA — typically 40–65 screens mapped per MVP.

backend-architect
Phase 3

Firestore schema, security rules, indexes, and cost model — before a single line of app code is written.

ux-designer
Phase 4 (3 audit rounds)

Catches structural rule violations, nav UX failures, WCAG AA contrast issues, and Featured-app polish gaps. Beta cannot ship until critical issues are closed.

copy-reviewer
After marketing copy

Audits every line of marketing copy against the venture’s tone-of-voice rules. No agency-speak slips through.

financial-modeler
Phase 2.5

Eight financial files: build costs, opex, revenue model, unit economics, cash flow, marketing budget, hiring plan, sensitivity analysis.

investor-readiness-reviewer
Phase 2.5

Recommended raise size, valuation range, dilution, red flags. Used to pressure-test the Financials Hub before Gate 2.5.

scope-loop-reviewer
Phase 2.5

Scope-change recommendations that loop back into Research and Define. Catches misaligned scope before the SOW is signed.

video-producer
Workstream C

Promotional video script, scene-by-scene breakdown, audio brief. Hand-off ready for production.

Each agent runs in sequence with defined inputs and outputs. The platform orchestrates the orchestra. Your program manager orchestrates the platform.
